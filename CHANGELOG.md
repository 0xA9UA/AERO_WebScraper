# Changelog

## 0.2.0 — 2026-09-30

Replaced backend-driven collection with eight native ChatGPT instruction workflows.
Added native capability routing, bounded browse queues, evidence notes, orthogonal
inspection/file-capture states, scoped retrieval, and explicit checkpoint/resume rules.
Added declarative catalog and checkpoint templates; retained technical taxonomy concepts.
Removed active Python runtime, custom tool contracts, daemon/server dependencies, and
package-installation requirements from the clean source/package.

Preserved plugin identity, private audience, skill names, and exact listing defaultPrompt.
The repository history retains 0.1.0; no force-push or history rewrite is required.
The installed account migration empties MCP maps and neutralizes obsolete files because
its updater cannot delete paths. No existing collected library is migrated or deleted.

Instruction-level retrieval preferences replace backend gates; they do not provide the
old server-side guarantees. The old 77-test result does not validate this redesign.
