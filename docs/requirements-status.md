# Requirements status for 0.1.0

The supplied specification remains authoritative in `user-specification.md`. This is a
first local backend release, not a claim that every requested deployment/integration is complete.

| Area | Status |
|---|---|
| Coordinator + specialist workflows | Eight skills in one private plugin package; no cross-plugin delegation invented |
| Shared storage/taxonomy | Original trees retained in taxonomy; content objects, versioned records, pointer projections |
| Required typed tools | All eleven implemented and discovered through actual local stdio |
| Document/repository/binary workflow | Synthetic end-to-end demonstration completed; binary is retained, not analyzed |
| Policy and retrieval | Operator-managed default-deny rights and OFF gate with egress checks |
| Acquisition | Approved seeded HTTP(S) crawler with fixture tests; not live-tested |
| Extraction | Text/HTML/PDF text, CSV/TSV text, bounded archive source members; images/binaries opaque |
| Permissions/archives/network | Implemented controls tested with fixtures; not independent adversarial security certification |
| Resumption/concurrency | Local process-level imports and crash-replay tested; strict failed-transfer accounting still limited |
| Search/RAG | Lexical/literal first; semantic indexing is optional and not implemented |
| Exports/intake | Ordinary copied files and explicit advisory-reference intake tested |
| MMA | Cohesive modules, concise source headers, maintained root index |
| Cloud hosting/web-mobile runtime | Not deployed or connected; account package saving alone cannot provide it |
| Production parser isolation/remote auth | Not implemented; required before hostile or public exposure |

See `test-results.md`, `security-and-limitations.md`, and `deployment.md` for evidence,
known gaps, and operator setup. Normal AERO research remains independent of optional retrieval.
